# Data Collection

This section provides runnable data-collection examples organized by
environment and input device. Each environment has its own installation guide
and a set of device-specific examples, so environment setup is completed once
and shared across all supported control methods.

Choose an environment first, complete its installation, and then follow the
example for the device you want to use.
